## Cafe Timer
A cozy focus timer styles like ordering a café 
inspired by @https://focusmatcha.com ☕

## Features
- 🌗 Light / dark theme toggle
- ☕ Three brew-based focus sessions
- ⏸️ Pause & resume support
- 🔔 chime + vibration when your session ends


## Build With
 - HTML5 
 - CSS3
 - JAVASCRIPT

## Steps
1. Click on the moon icon to change the theme
1. There are three options available:
   Espresso 15 minutes
   Latte 25 minutes
   Matcha 45 minutes
2. Click on the options given inside the Cafe menu.
3. Click on the moon icon to change the theme
4. Pause or stop your session whenever you need to 
4. Select your option and enjoy the process! 🤎
